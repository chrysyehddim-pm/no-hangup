# 不要掛電話｜互動鬼故事 Demo（Refined）

這是一個可直接上傳 GitHub Pages 的手機版互動鬼故事 Demo。

## 內容

- 視覺小說式互動頁
- 9:16 手機直式版型
- 對話框＋選項按鈕
- Jump scare 鬼影疊圖
- 三個結局
- 簡易音效：BGM、答鈴、呼吸答鈴、驚嚇音效、通知音、結局音效

## 使用方式

1. 解壓縮 zip
2. 直接開啟 `index.html` 測試
3. 上傳整個資料夾到 GitHub repo
4. GitHub Settings → Pages → Deploy from branch → main → Save

## 檔案結構

```text
index.html
style.css
script.js
assets/images/
assets/audio/
```

## 備註

目前圖片中的部分 UI 文字已經直接烘焙在圖片裡，HTML 另外用透明 hotspot 與動態對話框完成互動。若要做第二版，可改為「無文字背景圖 + HTML 文字 UI」以便日後維護。
